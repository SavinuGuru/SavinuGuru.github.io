Cybersecurity CTF Box

Individual · Level 5

Designed and built a self-hosted Capture-The-Flag environment on an isolated Ubuntu Server VM, covering five categories: session hijacking, binary exploitation, cryptography, steganography, and container security. Wrote and solved 10 full exploit chains end to end, including stealing a session cookie via reflected XSS, building a working ROP chain to bypass NX protection, cracking an MD5 hash with Hashcat, recovering a hidden message from LSB image steganography, and escaping a privileged Docker container to read the host filesystem. Backed every challenge with two peer-reviewed research papers on the underlying technique, then wrote a full risk assessment, threat scenario, and incident-response plan for each vulnerability class.
